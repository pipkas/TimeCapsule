# TimeCapsule

## Описание проекта

Мобильное Android-приложение для создания писем себе в будущее. Пользователь записывает сообщение, выбирает дату открытия, а приложение сохраняет его до наступления указанного дня.

Приложение работает офлайн и хранит все письма локально на устройстве.

## Технологический стек

- **Kotlin** — основной язык разработки.
- **Jetpack Compose** — создание пользовательского интерфейса.
- **ViewModel** — хранение и управление состоянием экранов.
- **Kotlin Coroutines** — выполнение операций с хранилищем вне основного потока.
- **StateFlow** — передача актуального состояния из ViewModel в интерфейс.
- **Room** — локальная база данных для сохранения писем.

## Основные пользовательские сценарии

### 1. Создание письма

Пользователь открывает форму создания письма, вводит заголовок и текст, выбирает дату открытия и сохраняет запись.

После сохранения письмо появляется в списке закрытых капсул.

### 2. Просмотр закрытых писем

Пользователь открывает список созданных капсул и видит заголовок письма и дату, когда его можно будет прочитать.

До наступления выбранной даты содержимое письма недоступно через интерфейс приложения.

### 3. Открытие письма

Когда наступает дата открытия, пользователь может открыть письмо и прочитать его содержимое.

После открытия письмо отображается в истории прочитанных писем.

### 4. Просмотр истории

Пользователь открывает историю и просматривает письма, которые уже были доступны для чтения.

Из истории можно открыть любое письмо и перечитать его.

## Основные экраны

1. **Главный экран** — список закрытых капсул и кнопка создания письма.
2. **Экран создания письма** — поля заголовка и текста, выбор даты и кнопка сохранения.
3. **Экран письма и истории** — просмотр доступного письма и список ранее открытых писем.

Экран просмотра письма может использоваться как для открытия новой капсулы, так и для повторного чтения уже открытого письма.

## Критерии готовности

Приложение считается готовым, если выполнены следующие условия:

- [ ] Пользователь может создать письмо с заголовком, текстом и датой открытия.
- [ ] Приложение не позволяет сохранить письмо без обязательных полей.
- [ ] Созданные письма сохраняются в локальной базе данных Room.
- [ ] Закрытые письма отображаются в отдельном списке с датами открытия.
- [ ] Письмо нельзя открыть раньше установленной даты через интерфейс приложения.
- [ ] После наступления даты открытия письмо становится доступным для чтения.
- [ ] Открытые письма отображаются в истории.
- [ ] После закрытия и повторного запуска приложения письма и их статусы сохраняются.
- [ ] Интерфейс реализован с помощью Jetpack Compose.
- [ ] Для управления состоянием используется ViewModel и StateFlow.
- [ ] Операции с локальным хранилищем выполняются с использованием Coroutines.
- [ ] Основные сценарии работают без подключения к интернету.

## Ограничения проекта

Чтобы сохранить проект простым, в первую версию не входят:

- регистрация и авторизация;
- серверная часть и синхронизация между устройствами;
- уведомления о наступлении даты открытия;
- вложения, фотографии и аудиозаписи;
- редактирование и удаление писем;
- сложные анимации и дополнительные настройки.

## Планируемый результат

Небольшое Android-приложение, в котором можно создавать личные капсулы времени, сохранять их на устройстве и читать письма после наступления выбранной даты.
